Welcome to AurexClient. Download your file and follow the installation instructions below.

MINECRAFT 1.20.1

INSTALLATION GUIDE

01

DOWNLOAD AUREX

Press the gold download button below to download your client file.

02

OPEN MINECRAFT FOLDER

Press Win + R, type %appdata%\.minecraft and press Enter.

03

OPEN MODS FOLDER

Find the mods folder. If it doesn't exist, create one.

04

MOVE THE FILE

Place the downloaded compatible .jar file into the mods folder.

05

START MINECRAFT

Launch Minecraft 1.20.1 using the compatible Forge or Fabric profile.

IMPORTANT: Make sure your downloaded file is a compatible Minecraft mod and that you use its required mod loader.
